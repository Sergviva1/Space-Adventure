# Соответствующие исходники runtime

## Выбранный способ распространения

Для публичного релиза выбран способ по GPLv3 §6(d): рядом с игровым ZIP на той же странице загрузки предоставляется отдельный ZIP исходников runtime, бесплатно и с равнозначным доступом. Письменное предложение по §6(b) не используется. Одни ссылки на сервер MSYS2 не заменяют публикацию подготовленных исходников вместе с релизом.

Имя отдельного архива:
`SpaceAdventure-runtime-sources-gcc-15.2.0-8-winpthreads-13.0.0.r124.g2717de84e-1.zip`.

Подготовка из корня проекта (Windows PowerShell 5.1 или новее):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-runtime-sources.ps1
```

Скрипт скачивает отсутствующие файлы с `https://mirror.msys2.org/mingw/sources/`, проверяет зафиксированные SHA-256 и создаёт ZIP в `dist/`. Повреждённый файл кэша вызывает ошибку, а не включается в архив. Кэш: `dist/runtime-sources/`. Исходные архивы не коммитятся в Git. Для каждого ZIP создаётся файл `.sha256`.

В Git сохранены `runtime-sources-sha256.txt`, `.BUILDINFO` обоих бинарных пакетов и настоящая инструкция. В архиве исходников они находятся в корне; в игре и репозитории — в `licenses/`.

## Использование исходников

Распакуйте ZIP, затем нужный `.src.tar.zst` в MSYS2 с помощью `tar --zstd -xf имя-архива`. Для GCC исходный код находится во вложенном `gcc-15.2.0.tar.xz`; изменения MSYS2 и команды сборки — в соседнем `PKGBUILD`. Для winpthreads исходники доступны в приложенном Git-репозитории `mingw-w64`; получить рабочее дерево можно командой `git clone ./mingw-w64 ./mingw-w64-work`, затем выполнить в нём `git checkout 2717de84ee9244ee84bf971dba2d621b81efbc35`.

Рецепты предназначены для MSYS2 UCRT64 (`MSYSTEM=UCRT64`) и инструментов makepkg MSYS2. Требуемые зависимости перечислены в `makedepends` рецептов; версии установленного окружения сборки зафиксированы в приложенных `.BUILDINFO`. Штатный запуск из каталога рецепта — `makepkg-mingw -s`; установка зависимостей требует доступа к пакетным репозиториям. Исторические зависимости не включены в ZIP, полная пересборка и побайтная воспроизводимость DLL не проверялись. Патчи и команды подготовки/компиляции/установки предоставляются без замены упрощённой инструкцией сборки.

GCC распространяется с исходными лицензионными уведомлениями; исключение GCC Runtime Library Exception не меняет MIT-лицензию авторского кода игры. winpthreads включён для полноты комплекта под применимыми уведомлениями MIT/BSD; это не утверждение о требовании GPL для winpthreads.

## Перед публикацией

1. Запустить скрипт и проверить итоговый ZIP и контрольные суммы после распаковки.
2. Опубликовать ZIP исходников рядом с игровым ZIP и его контрольной суммой. В описании релиза явно подписать ссылку «Исходники runtime GCC/MinGW».
3. Проверить доступность обеих загрузок без авторизации. Не удалять исходники, пока распространяется соответствующая сборка.
4. При распространении другим способом повторно проверить применимые условия: эта инструкция описывает сетевую раздачу, а не поставку на физических носителях.

Подготовка комплекта не означает, что релиз уже опубликован или все вопросы лицензирования проекта закрыты: старые ресурсы в истории Git рассматриваются отдельно.
