# Проверка локального архива SFML

## Проверенный файл

- Путь на машине проверки: `D:/Sergviva/Downloads/SFML-3.0.2-windows-gcc-14.2.0-mingw-64-bit.zip`.
- SHA-256: `9e62934512b710a2439134a413165bb87301373fced59b4ff6aedf5d736a7019`.
- Проверка всех записей ZIP через Python `zipfile.ZipFile.testzip()` завершилась без ошибок CRC.

## Сопоставление с репозиторием

- Все четыре поставляемые игровые DLL (`sfml-graphics-3.dll`, `sfml-window-3.dll`, `sfml-system-3.dll`, `sfml-audio-3.dll`) побайтно совпали с `SFML-3.0.2/bin/` в архиве.
- Все 114 файлов в `src/include/` совпали с соответствующими файлами архива после нормализации CRLF/LF; побайтно они отличаются.
- Из 103 файлов в `src/lib/` 95 совпали побайтно, восемь отличаются только переводами строк.
- Для каждого проверенного файла заголовков и библиотек найдена ровно одна соответствующая запись ZIP. Это сопоставление файлов репозитория, а не утверждение о полном равенстве содержимого архива и репозитория.
- Библиотеки и заголовки в ходе проверки не заменялись.

## Подтверждение источника

Автор проекта прямо подтвердил, что найденный ZIP в `Downloads` скачан непосредственно с официального сайта SFML. Имя локального ZIP и совпадение его содержимого с репозиторием проверены отдельно, как описано выше. Источник зафиксирован на основании подтверждения автора, а не независимого получения официальной копии.

Ожидаемый официальный URL:
https://www.sfml-dev.org/files/SFML-3.0.2-windows-gcc-14.2.0-mingw-64-bit.zip

При текущей проверке HTTPS-соединение с `www.sfml-dev.org` установить не удалось, в том числе с принудительным IPv4. Независимая копия по этому URL не получена; официальная контрольная сумма этого архива не установлена.

API официального GitHub-релиза https://github.com/SFML/SFML/releases/tag/3.0.2 доступен, но перечисляет MinGW-архивы под другими именами (`SFML-3.0.2-Windows.MinGW.x64.zip` и `SFML-3.0.2-Windows.MinGW.x86.zip`). Их равенство проверенному локальному архиву не установлено; автоматически считать их тем же комплектом нельзя.

Пункт фиксации источника и имени архива в плане релиза закрыт на основании подтверждения автора и локального сопоставления файлов. Независимая проверка по официальной копии или опубликованной официальной контрольной сумме остаётся невыполненной; подтверждение автора не следует представлять как такую проверку.
