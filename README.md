# Space Adventure

Космическая 2D-аркада для Windows x64 на C++17 и SFML 3. Собирайте монеты, уклоняйтесь от метеорита и продержитесь как можно дольше: у персонажа три жизни, а лучший результат сохраняется между запусками.

Проект [Sergviva1](https://github.com/Sergviva1). Первый публичный выпуск готовится; готовой загрузки в Releases пока нет.

## Правила

- Монета приносит одно очко.
- Столкновение с метеоритом отнимает жизнь и возвращает персонажа на старт.
- После урона действует двухсекундная неуязвимость с миганием.
- Лечение восстанавливает одну жизнь. При полном здоровье и во время неуязвимости бонус не расходуется.
- После поражения можно начать новую партию или вернуться в меню без перезапуска игры.
- В игре три зацикленных музыкальных трека и звуковые эффекты.

Игра работает в полноэкранном режиме с разрешением рабочего стола. Область 1920×1080 масштабируется с сохранением пропорций; на экранах другого формата возможны чёрные поля.

## Управление

| Экран | Клавиши |
| --- | --- |
| Меню | `Enter` — начать, `Esc` — выйти |
| Игра | `WASD` — движение, `N` — сменить музыку, `Esc` / `P` — пауза |
| Пауза | `Enter` / `Esc` / `P` — продолжить, `M` — меню, `Q` — выйти |
| Поражение | `R` / `Enter` — новая партия, `M` — меню, `Esc` — выйти |

При потере фокуса игра автоматически ставится на паузу. После возвращения в окно продолжите игру одной из клавиш возобновления.

## Сборка и запуск

Для запуска нужна Windows x64 с поддержкой графических и звуковых возможностей SFML 3. Компилятор нужен только для сборки.

Инструменты сборки — MSYS2 UCRT64, MinGW-w64 GCC и GNU Make. Проверено с GCC 15.2.0 и GNU Make 4.4.1. В терминале MSYS2 UCRT64 установите:

```text
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-make
```

Добавьте инструменты UCRT64 в `PATH`, перейдите в корень проекта и выполните:

```text
mingw32-make
```

SFML 3.0.2 уже включён: заголовки находятся в `src/include/`, четыре import-библиотеки для динамической release-сборки — в `src/lib/`. Статические и отладочные библиотеки не поставляются.

Запуск в PowerShell:

```powershell
.\main.exe
```

Рядом с `main.exe` должны находиться каталог `assets/` и семь DLL из корня репозитория: `libgcc_s_seh-1.dll`, `libstdc++-6.dll`, `libwinpthread-1.dll`, `sfml-audio-3.dll`, `sfml-graphics-3.dll`, `sfml-system-3.dll`, `sfml-window-3.dll`. Игра ищет ресурсы относительно EXE, поэтому рабочая папка может быть любой. Шрифт PT Sans включён в `assets/`.

Очистка исполняемых файлов: `mingw32-make clean`.

## Рекорд

Результат сохраняется в `%LOCALAPPDATA%\SpaceAdventure\highscore.txt` сразу после превышения прежнего рекорда. Все копии игры в одном профиле Windows используют этот файл. Чтобы сбросить рекорд, закройте игру и удалите файл.

Отсутствующий или повреждённый файл считается нулевым рекордом. При ошибке записи игра продолжает работать и показывает пометку «не сохранён»; следующая монета вызывает повторную попытку. Запись через временный файл защищает прежний результат от неудачной замены. Сохранения не включаются в архив игры.

## Проверки и архивы

```text
mingw32-make smoke
mingw32-make dist-check
```

`smoke` проверяет движение, границы, столкновения, лечение, неуязвимость, игровые состояния, музыку, сохранение рекорда и прокрутку фона. Тест использует временное сохранение, не затрагивая рекорд игрока. Сообщения об ошибках записи во время теста ожидаемы: проверяются и неудачные сохранения.

`dist-check` пересобирает игру, запускает smoke-тест, создаёт `dist/SpaceAdventure-local-win64.zip` и проверяет его после распаковки. Проверяются SHA-256, состав файлов, запуск теста и игры из другой рабочей папки, по пути с пробелами и кириллицей, с системным `PATH`. Требуется Windows PowerShell 5.1 или новее. Для создания архива без проверки распакованной копии есть `mingw32-make dist`.

Проверки открывают игровое окно: необходимы рабочий стол, графика и аудио. Не запускайте их параллельно. Они не заменяют ручное прохождение и проверку на отдельном компьютере.

Архивы с суффиксом `local` предназначены для проверки. При публичном распространении игры нужно также предоставить ZIP исходников runtime GCC/MinGW. Подготовить его можно командой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-runtime-sources.ps1
```

Подробности — в [licenses/runtime-sources.md](licenses/runtime-sources.md). Каталог `dist/` не включается в Git.

Демонстрационные скриншоты обновляются командой `mingw32-make screenshots`.

## Структура проекта

| Путь | Содержимое |
| --- | --- |
| `coding/main.cpp` | Точка входа и обработка ошибок запуска |
| `coding/Game.hpp` | Игровой цикл, состояния, события и столкновения |
| `coding/Player.hpp` | Движение, здоровье и анимация игрока |
| `coding/GameObjects.hpp` | Метеорит, монета и лечение |
| `coding/Background.hpp`, `HUD.hpp`, `Menu.hpp` | Фон и интерфейс |
| `coding/Sounds.hpp`, `HighScore.hpp` | Аудио и сохранение рекорда |
| `coding/Resources.hpp`, `Resources.cpp` | Пути ресурсов, общие функции и генератор случайных чисел |
| `assets/` | Текстуры, музыка, эффекты и шрифт |
| `tests/`, `scripts/` | Проверки, скриншоты и упаковка |
| `src/` | Заголовки и import-библиотеки SFML |
| `licenses/` | Уведомления сторонних компонентов и сведения об исходниках runtime |

Методы игровых классов определены в заголовках. План развития и состояние проверок — в [SPEC.md](SPEC.md).

## Замена текстур

- `spritelist.png`: 166×260, два кадра 166×130 друг под другом.
- `healthbar.png`: 312×311; полная полоска — `(0, 0, 312, 104)`, пустая — `(0, 207, 312, 104)`.
- `meteor.png`, `coin.png`, `bonus.png`: вписываются в 125×125, 96×96 и 92×92 соответственно.
- `gameover.png`: вписывается в 1000×340.
- `space.png`, `gamepanel.png`: заполняют игровую область 1920×1080; панель — прозрачная рамка.

Для спрайтов нужен прозрачный фон без больших пустых полей: столкновения считаются по прямоугольникам. При замене ресурсов обновляйте сведения об источниках и лицензиях.
