# История изменений

## 0.1.0

Первый выпуск Space Adventure для Windows x64.

### Игра

- Главное меню, пауза и экран поражения с возможностью начать новую партию.
- Управление WASD с одинаковой скоростью по прямой и диагонали.
- Метеорит, монеты, лечение, три жизни и временная неуязвимость после урона.
- Сохранение рекорда в профиле Windows.
- Анимация персонажа и прокручиваемый космический фон.
- Три музыкальных трека, переключение по N и звуковые эффекты.
- Автоматическая пауза при потере фокуса.
- Полноэкранное масштабирование игровой области с сохранением пропорций.

### Сборка

- Ресурсы, шрифт и необходимые DLL включены в игровой архив.
- Загрузка ресурсов относительно EXE, независимо от рабочей папки.
- Smoke-тест и автоматическая проверка распакованной сборки.
- Отдельный архив исходников runtime GCC/MinGW с рецептами и патчами MSYS2.

### Ограничения

- Поддерживается Windows x64.
- Доступен полноэкранный режим; оконный режим и настройки громкости не предусмотрены.
- Столкновения рассчитываются по прямоугольникам спрайтов.
