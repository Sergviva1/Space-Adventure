# Состояние проекта и план развития

## Текущая версия

Космическая 2D-аркада для Windows x64 на C++17 и SFML 3.0.2. Основной игровой цикл реализован; сборка подготовлена для локальной проверки. Публичный релиз пока не опубликован.

## Реализовано

- Главное меню, игра, пауза и экран поражения с итоговым счётом.
- Новая партия и возврат в меню без перезапуска приложения.
- Движение WASD с одинаковой скоростью по прямой и диагонали.
- Три жизни, урон, две секунды неуязвимости и мигание персонажа.
- Монеты, лечение и сохранение рекорда в профиле Windows.
- Анимация персонажа и бесшовная прокрутка фона.
- Три зацикленных музыкальных трека, переключение по нажатию N и звуковые эффекты.
- Пауза при потере фокуса; продолжение только по команде игрока.
- Полноэкранный режим в разрешении рабочего стола и масштабирование области 1920×1080 с сохранением пропорций.
- Загрузка ресурсов относительно EXE, поставляемый шрифт и сообщения об ошибках загрузки.
- Ограничение шага обновления до 50 мс и частоты кадров до 120 кадров/с.
- Smoke-тесты, создание ZIP и проверка распакованной сборки.
- Скриншоты, инструкция сборки, сведения об источниках ресурсов и лицензии.

## Проверки

Проверены команды `mingw32-make clean` и `mingw32-make dist-check` на Windows с GCC 15.2.0 и GNU Make 4.4.1:

- Чистая сборка с `-Wall -Wextra -Wpedantic` без предупреждений.
- Smoke-тест границ движения, столкновений, лечения, неуязвимости, игровых состояний, аудио, рекорда и прокрутки фона.
- Проверка состава ZIP, SHA-256 файлов и наличия лицензий.
- Smoke-тест распакованной копии и кратковременный запуск игры с системным PATH, из другой рабочей папки, по пути с пробелами и кириллицей.

Эти проверки не заменяют ручное прохождение и запуск на отдельной чистой Windows-машине.

## Зависимости

- SFML DLL совпали по SHA-256 с предоставленной папкой `SFML-3.0.2/`. Заголовки и файлы библиотек также сопоставлены; текстовые различия ограничены переводами строк. Сам SFML не заменялся.
- Runtime обновлён из текущего MSYS2 UCRT64: `gcc-libs 15.2.0-8` и `libwinpthread 13.0.0.r124.g2717de84e-1`.
- Версии пакетов, границы проверки и условия распространения описаны в [licenses/README.md](licenses/README.md); контрольные суммы — в `licenses/runtime-sha256.txt`.
- Условия ресурсов и сведения об их источниках — в [assets/LICENSE.md](assets/LICENSE.md) и [CREDITS.md](CREDITS.md).
