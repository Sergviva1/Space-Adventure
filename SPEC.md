# Состояние проекта и план развития

## Текущее состояние

Космическая 2D-аркада для Windows x64 на C++17 и SFML 3.0.2. Игровой цикл реализован, локальная сборка и упаковка работают. Первый публичный релиз ещё не опубликован.

## Реализовано

- Главное меню, игра, пауза, экран поражения, новая партия и возврат в меню.
- Управление WASD с одинаковой скоростью по прямой и диагонали.
- Три жизни, урон, лечение, две секунды неуязвимости и мигание персонажа.
- Монеты, счёт и сохранение рекорда в профиле Windows.
- Анимация персонажа, прокрутка фона, музыка и звуковые эффекты.
- Смена трека по нажатию N и автоматическая пауза при потере фокуса.
- Полноэкранный режим с масштабированием области 1920×1080 без искажения пропорций.
- Загрузка ресурсов относительно EXE, встроенный шрифт и обработка ошибок загрузки.
- Ограничение шага обновления до 50 мс и частоты кадров до 120 кадров/с.
- Разделение исходников по ответственности, smoke-тесты, упаковка и проверка ZIP.

## Проверки

Сборка проверена на Windows с GCC 15.2.0 и GNU Make 4.4.1, с флагами `-Wall -Wextra -Wpedantic`, без предупреждений.

`mingw32-make dist-check` проверяет игровые состояния, границы движения, столкновения, лечение, неуязвимость, аудио, сохранение рекорда и прокрутку фона. Дополнительно проверяются состав ZIP, SHA-256 и запуск распакованной копии из другой рабочей папки, по пути с пробелами и кириллицей, с системным `PATH`.

На основном компьютере пройдена ручная проверка игрового маршрута, управления, паузы, переключения музыки и звука. Проверка на отдельном Windows-компьютере без инструментов разработки и на других экранах пока не выполнена.
