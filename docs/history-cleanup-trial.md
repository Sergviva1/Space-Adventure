- Незакоммиченные изменения документации и скриптов сохранены в backup, но не добавлены в очищенную историю. Сравнение деревьев и сборка относятся к зафиксированному исходному HEAD.
- На GitHub ничего не отправлялось; force-push не выполнялся.
- Скрытые ссылки pull request, форки и чужие клоны не очищались.
- Ручное прохождение игры не выполнялось.

## Следующий шаг — только после согласования

Выбрать способ переноса незакоммиченной подготовки релиза в очищенную историю, проверить конечное состояние, затем согласовать замену **только** `refs/heads/main` на GitHub. Перед отправкой повторно проверить удалённый HEAD и использовать защиту от перезаписи неожиданно появившихся чужих коммитов (`--force-with-lease` с явным ожидаемым SHA). Не применять `push --mirror`.

Пункт очистки публичной истории в SPEC остаётся открытым: локальный пробный результат не означает очистку GitHub.
