## Библиотеки

- [SFML 3.0.2](https://www.sfml-dev.org/) — zlib/png.
- [GCC runtime](https://gcc.gnu.org/) — GPL 3.0 с GCC Runtime Library Exception 3.1.
- [MinGW-w64 / winpthreads](https://www.mingw-w64.org/) — соответствующие уведомления MIT/BSD и runtime.

SFML включает сторонние компоненты; их уведомления, версии и источники перечислены в [licenses/README.md](licenses/README.md). Этот каталог должен сохраняться в распространяемой сборке. Исключение GCC Runtime Library Exception позволяет сохранить MIT-лицензию кода игры; условия раздачи самих runtime-DLL учитываются отдельно. Инструкция по предоставлению исходников — [licenses/runtime-sources.md](licenses/runtime-sources.md).
