Все перечисленные старые текстуры, музыкальные треки и WAV-эффекты удалены из рабочей копии и не включаются в сборку. Сведения об их источниках и разрешениях на распространение не предоставлены. Удаление из рабочей копии не удаляет уже закоммиченные файлы из истории Git: вопрос их присутствия в публичной истории остаётся отдельной задачей. Аудит 49 достижимых коммитов выявил 18 уникальных старых объектов в `assets/` и `coding/assets/`; точные пути и версии — в [отчёте](docs/asset-history-audit.md). Старые и актуальные текстуры частично имеют одинаковые имена, поэтому удалять все версии по этим путям нельзя. После аудита история очищена по ID старых объектов, ветка `main` на GitHub заменена и проверена сборкой. Однако GitHub сохраняет старую историю через `refs/pull/1/head`; полная очистка сервера пока не завершена (см. [результат публикации](docs/history-cleanup-publication.md)). Готовый публичный архив игры не публиковался.

## Библиотеки

Игра использует [SFML 3.0.2](https://www.sfml-dev.org/) по лицензии zlib/png и runtime-библиотеки MinGW-w64/GCC. Тексты лицензий SFML, встроенных зависимостей и runtime включены в каталог [licenses/](licenses/README.md) и локальный ZIP. Там приведены источники текстов, область действия и оставшиеся вопросы проверки бинарников и предоставления соответствующих исходников. Автор сообщил, что скачал библиотеки с официального сайта SFML. SFML DLL побайтно совпали с позднее предоставленной папкой `SFML-3.0.2/`; заголовки и библиотеки также сопоставлены (подробности в `licenses/README.md`). Дополнительно проверен найденный локальный ZIP `SFML-3.0.2-windows-gcc-14.2.0-mingw-64-bit.zip`: CRC без ошибок, четыре игровые DLL совпали побайтно, заголовки и библиотеки также сопоставлены. SHA-256 и границы проверки — в [licenses/SFML-verification.md](licenses/SFML-verification.md). Автор прямо подтвердил, что найденный архив скачан непосредственно с официального сайта SFML. Независимая официальная копия для сравнения пока не получена; подтверждение автора не является независимой проверкой.

Для `libgcc_s_seh-1.dll` и `libstdc++-6.dll` приложены GPL 3.0 и GCC Runtime Library Exception 3.1; для winpthreads — уведомления MIT/BSD. Это не меняет MIT-лицензию авторского кода. Прежние три runtime-DLL были взяты из компилятора до переустановки системы. Теперь они заменены копиями из текущего MSYS2 UCRT64: `gcc-libs 15.2.0-8` и `libwinpthread 13.0.0.r124.g2717de84e-1`; принадлежность файлов пакетам проверена через pacman, контрольные суммы обновлены. Тексты лицензий побайтно совпадают с уведомлениями установленного комплекта. Соответствующие исходные архивы MSYS2 и рецепты проверены и подготовлены для отдельного ZIP. При публичной сетевой раздаче его необходимо опубликовать рядом с игрой с равнозначным доступом; одних текстов лицензий недостаточно. Команда упаковки, подтверждения и границы проверки — в [licenses/runtime-sources.md](licenses/runtime-sources.md).
